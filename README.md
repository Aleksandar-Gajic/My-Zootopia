# Animals Web Generator

Animals Web Generator is a fun Python project that fetches animal data from the Ninja API and generates a beautiful HTML website with all the information you need about the animal of your choice. No zoos, no cages, just code and cute animals! Perfect for anyone who loves animals, learning Python, or just wants a magical way to see creatures pop up on their browser.

## Installation

To install this project, simply clone the repository: git clone https://github.com/Aleksandar-Gajic/My-Zootopia.git
cd animals-web-generator

Then install the required dependencies: pip install -r requirements.txt

Create a `.env` file in the root folder and add your Ninja API key like this: API_KEY=‘your_actual_api_key_here’

The `.env` file is ignored by Git, so your key stays safe.

## Usage

To use this project, run the following command: python animals_web_generator.py

When prompted, type the name of an animal (e.g., `Fox`). The program will generate an `animals.html` file that you can open in your browser. If the animal doesn’t exist, a friendly message will appear instead.
